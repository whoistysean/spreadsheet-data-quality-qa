Spreadsheet Data Quality & Quality Assurance

A beginner portfolio project demonstrating how spreadsheets can support AI data annotation, dataset organization, and quality assurance.

Learning Objectives

* Use spreadsheet filters to review annotation records.
* Understand COUNTIF formulas.
* Identify incorrect annotations.
* Detect missing labels and duplicate records.
* Maintain consistent and reliable datasets.
